# STM32 智能小车 (开发中)

基于 STM32F103 的智能小车项目。当前处于**模块化驱动开发阶段**，各外设驱动已基本完成，主控逻辑仍在迭代中。

## 硬件平台

- **MCU**: STM32F103C8T6 (Cortex-M3, 72MHz)
- **开发环境**: Keil MDK-ARM v5
- **库**: STM32 标准外设库

## 当前运行功能

main.c 当前实际运行的功能：

- **OLED 显示屏** — 实时显示数据（I2C 软件模拟）
- **HC-SR04 超声波测距** — 每100ms采集一次距离值并显示在OLED上

> 注：这是一个**超声波测距仪**的当前状态，不是完整的智能小车控制系统。

## 硬件引脚分配

```
PA2  ── TIM2_CH3  ── 左电机 PWM
PA3  ── TIM2_CH4  ── 右电机 PWM
PA6  ── GPIO_Out   ── 超声波 Trig / 电机方向控制 (⚠️ 共用!)
PA7  ── GPIO_IPD   ── 超声波 Echo
PA8/PA9           ── 电机方向控制
PB8  ── GPIO_OD    ── OLED SCL (I2C软件模拟)
PB9  ── GPIO_OD    ── OLED SDA (I2C软件模拟)
PB10 ── USART3_TX  ── 串口发送
PB11 ── USART3_RX  ── 串口接收
PA1/PA2           ── 按键输入
```

## 使用方法

1. 用 Keil MDK-ARM 打开 `32test.uvprojx`
2. 编译 (F7) → 下载 (F8) 到开发板
3. OLED 屏幕第1行会实时显示超声波测距数值
