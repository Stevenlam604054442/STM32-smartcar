# STM32 智能小车控制系统

基于 **STM32F103C8T6** 的智能小车系统，集成超声波避障、OLED人机交互、直流电机PWM控制、串口调试通信、红外遥控等多模块协同工作。

## 技术栈

| 类别 | 技术 |
|------|------|
| MCU | STM32F103C8T6 (ARM Cortex-M3, 72MHz) |
| 开发环境 | Keil MDK-ARM v5 |
| 驱动库 | STM32 Standard Peripheral Library |
| 通信协议 | I2C(软件模拟), USART3, 红外NEC(38kHz载波), GPIO, TIM(PWM+中断+输入捕获) |

## 功能特性

- **超声波测距** — HC-SR04 模块，TIM3 中断方式精确计时，量程 20~4000mm
- **OLED 实时显示** — 128×64 SSD1306，I2C 软件模拟驱动（PB8/PB9），4行状态面板
- **直流电机控制** — 双H桥四轮独立 PWM 调速（TIM2 输出比较，20kHz），正反转 + 无级变速
- **自动避障** — 基于距离阈值的 PID 式分段控制策略（全速→减速→后退）
- **串口人机交互** — USART3（9600bps），支持模式切换和手动方向指令，printf 重定向
- **红外遥控** — NEC 协议解码（TIM4 输入捕获），支持按键映射到小车动作
- **按键输入** — 双按键浮空输入检测

## 运行模式

| 模式 | 编号 | 触发方式 | 行为 |
|------|------|----------|------|
| 停止 | `0` | 上电默认 / 串口`0` / 红外按键`0` | 所有电机停止 |
| 自动避障 | `1` | 串口发送 `1` | 根据超声波距离自动前进/减速/后退 |
| 手动控制 | `2` | 串口发送 `2` / 红外方向键 | 通过 WASD 或红外遥控控制方向 |

### 控制指令对照表

| 动作 | 串口指令 | 红外遥控键(NEC) | OLED显示 |
|------|---------|-----------------|---------|
| 停止 | `0` | `0`(0x16) | Mode: STOP |
| 自动避障 | `1` | — | Mode: AUTO |
| 切换手动 | `2` | 方向键自动切换 | Mode: MANUAL |
| 前进 | `w`/`W` | `1`(0x18) | Spd RL: +60 |
| 后退 | `s`/`S` | `2`(0x5E) | Spd RL: -60 |
| 左转 | `a`/`A` | `3`(0x08) | 差速转向 |
| 右转 | `d`/`D` | `4`(0x1C) | 差速转向 |
| 急停 | `空格` | VOL+(0x15) | Spd RL: 0 |

## 使用方法

### 编译与下载

```bash
# 1. 用 Keil MDK-ARM 打开工程
打开 32test.uvprojx

# 2. 编译
按 F7 (Build)

# 3. 下载到开发板
按 F8 (Download)

# 4. 连接串口调试助手 (可选)
波特率: 9600, 数据位: 8, 停止位: 1, 校验: None
```

### 操作说明

1. **上电后**: OLED 显示 "System Ready!" → 切换到状态面板
2. **查看数据**: 第1行实时显示超声波距离值(mm)，第4行显示红外按键码
3. **切换模式**:
   - 串口端发送 `0`(停止)、`1`(自动避障)、`2`(手动)
   - 或用红外遥控器按键操作
4. **手动控制**: 进入模式2后，键盘 WASD 或红外方向键控制方向

## 设计亮点

### 1. 定时器资源隔离 (三定时器各司其职)

| 定时器 | 用途 | 工作模式 | 关键参数 |
|--------|------|----------|----------|
| **TIM2** | 电机 PWM 调速 | 输出比较 PWM1 | PSC=36, ARR=99 → **20kHz** (避免电机噪声) |
| **TIM3** | 超声波 Echo 计时 | 更新中断 | PSC=0, ARR=7199 → **10kHz** (0.1ms精度) |
| **TIM4** | 红外 NEC 解码 | CH1输入捕获 | PSC=71 → **1MHz**计数 (1us分辨率) |

> 设计原则：每个定时器只负责一个功能，互不干扰。解决了早期版本共用 TIM2 导致的 PWM 配置被覆盖的问题。

### 2. 分层模块化设计

```
应用层 (main.c)     ← 只写业务逻辑，不直接操作寄存器
       ↓
驱动层 (Hardware/)  ← 封装外设细节，提供统一 API (Init/Set/Get)
       ↓
硬件抽象层 (system/)← 底层定时器、SysTick延时、时钟配置
```
每个外设独立为 `.c/.h` 文件对，接口清晰，可单独测试和替换。

### 3. 多通道人机交互 (串口 + 红外双路)

- **串口通道**: ASCII 字符指令，适合 PC 端调试和日志输出
- **红外通道**: NEC 编码按键，适合手持遥控操作
- 两路输入共享同一套模式状态机，任一通道均可触发动作
- OLED 第4行实时回显红外按键码，便于调试确认

### 4. NEC 协议状态机解码 (IR.c)

```
空闲(State0) ──[13.5ms Start]──→ 等待引导(State1) ──[接收32bit]──→ 数据解析(State2)
     ↑                                    ↓                              ↓
     └──────────[11.25ms Repeat/Error]────┴──────────[校验通过]──────────┘
```
- 使用 TIM4_CH1 输入捕获精确测量脉冲宽度
- 内部实现完整的状态机：Start信号识别 → 逐位数据采集 → 校验验证 → 命令提取
- 支持数据帧和连发帧分离检测

### 5. 超声波避障策略 (三段式)

| 距离范围 | 速度设定 | 占空比 | 说明 |
|----------|---------|--------|------|
| > 200mm | +50 | 50% | 安全区域，全速前进 |
| 50~200mm | +25 | 25% | 警戒区域，减速通过 |
| < 50mm | -40 | 40% | 危险区域，后退避让500ms |
